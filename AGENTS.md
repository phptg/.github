# AGENTS.md

Special `.github` repository of the [PHPTG](https://github.com/phptg) GitHub organization (Telegram Bot API for PHP).
It contains no code — only organization-wide GitHub files.

## Structure

- `profile/README.md` — organization profile shown on https://github.com/phptg.
- `profile/logo.png` — logo used in the profile README.
- `FUNDING.yml` — sponsorship links, applied to all organization repositories without their own `FUNDING.yml`.
- `PULL_REQUEST_TEMPLATE.md` — default pull request template, applied to all organization repositories without their own template.

## Guidelines

- Keep funding links in `FUNDING.yml` and `profile/README.md` in sync.
- Reference images in `profile/README.md` by relative paths.
